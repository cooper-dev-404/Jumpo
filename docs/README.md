# Jumpo 文档索引

本目录集中保存 Jumpo 的产品规格、技术论证、验证记录和归档快照。
仓库根目录只保留 [README.md](../README.md)（工程运行说明）和 [AGENTS.md](../AGENTS.md)（协作约定）。

## 目录结构

| 目录 | 内容 | 变更策略 |
|---|---|---|
| `product/` | 当前有效的产品需求与交互设计规格 | 改行为先改规格；修订需更新文档头版本说明 |
| `technical/` | 技术可行性论证与发布前评审结论 | 结论变化时追加修订记录，不覆盖历史结论 |
| `validation/` | 实机验证、自动化测试与未验证事项记录 | 只追加新证据，保留历史小节 |
| `archive/` | 评审前原始快照 | **只读**，任何情况下不修改 |
| `assets/` | README 与文档引用的图片素材 | 截图按功能命名，随界面变更更新 |

## 文件命名规范

规格类文档使用 `Jump_<主题>_V<主版本>.<次版本>.md`：

- 主题用英文短语，`macOS`、`UI` 等专有写法保持原样。
- 版本号跟随产品版本；同一主题的破坏性修订升主版本，澄清性修订升次版本。
- 验证记录不参与编号，因为它按时间追加而非按版本发布。

`archive/2026-09-30_before_review/` 中保留的是评审前原文，文件名与内容都与当时一致，
即使与上述规范冲突也不调整。

## 维护约定

- 修改界面或行为前先更新 `product/` 中的对应章节，再改代码。
- 每次封版后把实测结果追加到 `validation/Prototype_Validation.md`，并注明构建方式、系统版本和签名状态。
- 只有 `validation/` 中明确通过的项目才算已验证；需求和设计的完成度不等于实现完成度。
- 归档目录 `archive/` 只增不改，用于追溯评审前的原始意图。
